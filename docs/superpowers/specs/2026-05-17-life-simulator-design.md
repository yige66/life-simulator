# 异世界人生模拟器 (Life Simulator) 设计文档

## 1. 项目概述
创建一个基于 React + TypeScript + Next.js 的单页网页游戏，采用二次元 GalGame/轻小说视觉风格，结合 DeepSeek API 实现动态剧情生成。

## 2. 视觉与交互设计 (UI/UX) - 华丽装饰派 (Ornate Style)
- **核心布局风格**:
  - **属性面板 (幻想魔法阵)**: 使用动态旋转的星光圆环作为背景，属性数字居中显示，四项属性分布在魔法阵的四个方位，带有神秘的符文动效。
  - **对话框 (古典画框)**: 采用双线双弧形的优雅边框，背景带有极高的磨砂质感和淡淡的羊皮纸纹理，底部带有指向性的小三角。
  - **按钮与选项 (现代极光)**: 选项按钮四角带有发光的 L 型护角装饰，悬停时产生强烈的极光扩散效果。
- **配色方案**:
  - 背景: 深邃夜空紫 (#1A0B2E 到 #2E073F 渐变)
  - 装饰/强调: 樱花粉 (#FFB7C5) 与 极光青 (#A7F3D0)
  - 文字: 月光白 (#F5F5F7)
- **动画增强**:
  - 页面切换带有“星门开启”般的放射状淡入淡出。
  - 属性变动时，魔法阵会产生剧烈的闪烁反馈。
- **字体**: Google Fonts `M PLUS Rounded 1c`。

## 3. 核心功能流程
### 3.1 角色创建
- 玩家输入: 名字、身份背景 (自由输入)。
- 属性分配:
  - 初始属性: 智力/魅力/体力/运气 各 3 点。
  - 自由点数: 5 点。
  - 属性上限: 8 点。

### 3.2 篇章生成
- 调用 API，基于背景生成 2-4 个篇章标题。
- 每个篇章包含 4-6 个随机事件。

### 3.3 游戏循环
- 每回合调用 API 生成事件 JSON:
  - 增加选项数量（3-4个）。
  - **自由输入模式**: 提供一个输入框，允许玩家自定义回答。
  - **智能分析**: 若玩家选择自定义回答，将该文本传给 API，分析其对各项属性的影响（例如：玩家回答“我决定用魔法点燃这些火把”，API 判定智力+1，体力-1）。
- 状态维护: 玩家名字、背景、属性、篇章信息、历史摘要 (最近 3 回合)。

### 3.4 结局生成
- 篇章结束后，基于全程摘要和最终属性生成 100-200 字结局。

## 4. 技术栈与架构
- **前端**: Next.js 14 (App Router), React, TypeScript, Tailwind CSS, Framer Motion.
- **后端**: Next.js API Route (`/api/deepseek`) 作为安全代理。
- **状态管理**: React Context 或简单的 `useState` (单页应用量级)。
